# Диагностика лаунчера

## Проблемы с графикой в Linux

Если окно пустое, мерцает или приложение падает при изменении размера, см. [Проблемы с графикой в Linux: NVIDIA и Wayland](/docs/ru-RU/guides/nvidia-wayland). Там описаны переменные WebKitGTK, сравнение результатов и сбор информации, когда лаунчер не открывается.

## Сообщение об ошибке

См. [Поддержка](/docs/ru-RU/guides/support), чтобы сообщить об ошибке с журналами и шагами для её воспроизведения.
