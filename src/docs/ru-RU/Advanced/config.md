# Настройка лаунчера

Настройки открываются по значку шестерёнки на боковой панели и разделены на четыре вкладки: **Лаунчер**, **Minecraft**, **Персонализация** и **Java**. Изменения сохраняются автоматически.

## Вкладка «Лаунчер»

### Общие

- **Язык** — меняет язык интерфейса. Доступны испанский, английский, французский, немецкий, украинский, японский и русский.
- **Проверять обновления при запуске** — проверяет наличие новой версии при открытии лаунчера.
- **Активность в Discord** — показывает активность CubicLauncher в Discord.
- **Скрывать лаунчер во время игры** — сворачивает или скрывает окно при запуске Minecraft.
- **Открывать консоль при запуске инстансов** — открывает окно журнала при запуске инстанса.
- **Заметные уведомления** — использует крупные центрированные уведомления с заголовками в верхнем регистре и более разборчивым текстом.
- **Тестовое уведомление** — показывает предпросмотр текущих уведомлений.

### Хранилище

Позволяет выбрать диск, на котором хранятся инстансы и общие файлы:

- **Расположение инстансов** — показывает текущий путь и количество инстансов. Его можно изменить или сбросить до расположения по умолчанию.
- **Перемещение с помощью жёстких ссылок** — если целевой диск это поддерживает, инстансы перемещаются без дублирования данных. Если целевой диск другой, данные копируются.
- **Исходные файлы удаляются только после того**, как каждый инстанс полностью перенесён в новое место. Если что-то пойдёт не так, лаунчер покажет, какие файлы не удалось переместить.
- **Общие файлы** — показывает место, занятое версиями, библиотеками, assets и средами выполнения. Можно изменить расположение, сбросить его или удалить всё содержимое.
- Удаление общих файлов не затрагивает ваши миры и настройки: версии и библиотеки скачиваются заново при запуске инстанса.
- Новая папка общих файлов должна быть пустой. Закройте Minecraft и дождитесь завершения загрузок, прежде чем менять эти пути.

Конфигурация хранится в `settings.cub`, а пользовательские пути считываются при запуске лаунчера.

### Темы

- Показывает активную тему.
- **Импортировать тему** — загружает ZIP или `.cbth`.
- **Просмотреть темы** — открывает веб-каталог тем.
- **Экспортировать** — сохраняет активную тему для передачи другим.
- **Удалить** — удаляет тему, установленную пользователем.

### Производительность

- **Уменьшить анимации интерфейса**.
- **Отключить эффекты размытия**.
- **Отключить непрерывные анимации загрузки**.
- **Отключить анимацию 3D-просмотра скина**.
- **Уменьшить анимации журнала**.

Эти параметры помогают на слабом оборудовании или если вам нужен более сдержанный интерфейс.

### Обновления

- Показывает текущую версию и наличие обновления.
- **Канал обновлений** — стабильный или предварительный.
- Позволяет проверять обновления, просматривать примечания к выпуску, скачивать и устанавливать их.
- Дата последней успешной проверки отображается в этом разделе.

### О программе

Содержит ссылки на Discord, исходный код и сообщение об ошибках.

## Вкладка Minecraft

### Производительность (ОЗУ)

- **Минимум** и **максимум** памяти в ГБ.
- **Использовать рекомендуемый объём ОЗУ** рассчитывает диапазон на основе общей памяти компьютера.
- Глобальная память используется, если у инстанса нет переопределений.

### Параметры Minecraft

- **Показывать снапшоты**.
- **Показывать версии Alpha**.
- **Показывать нестабильные версии загрузчиков**.

Эти параметры влияют на версии, отображаемые в загрузчике и при создании инстансов.

### Источник загрузок

- **Официальный (Mojang)** — официальные серверы; рекомендуется за пределами Китая.
- **BMCLAPI (Китай)** — зеркало для игроков из Китая с медленной загрузкой. Если зеркало недоступно, лаунчер переключается на официальные серверы.

Источник применяется к метаданным, assets, библиотекам, а также к установке Forge, NeoForge, Fabric и OptiFine.

### Параметры консоли

- **Лимит истории** — количество строк, хранимых для каждого инстанса (от 100 до 5000).
- **Показывать теги уровней** — полезно для фильтрации журналов. Скрывать их не рекомендуется.

### Профили options.txt

- Создание, редактирование, импорт и удаление профилей `options.txt`.
- Назначение профиля инстансу из его редактора.
- Применение профиля вручную или автоматически перед запуском.
- При замене существующего `options.txt` сохраняется резервная копия.

:::warning Экспериментальная функция
Профили `options.txt` могут измениться в будущих версиях. Автоматическое применение профиля заменяет файл инстанса; изменения, сделанные в игре, будут потеряны при следующем запуске.
:::

## Вкладка «Персонализация»

### Интерфейс

- **Масштаб интерфейса** — меняет размер всего окна. 100 % — исходный размер.
- **Плотность** — «Тема», «Компактная» или «Комфортная». Настраивает отступы между карточками, списками и параметрами, не меняя шрифт.
- **Шрифт** — «Тема» или один из шрифтов, включённых в лаунчер.
- **Сбросить интерфейс** — возвращает значения по умолчанию.

### Уведомления

- Включает или отключает настройку уведомлений.
- **Положение** — шесть углов или краёв экрана.
- **Размер блока** — «Компактный», «Обычный» или «Широкий».
- **Размер заголовка** и **размер сообщения**.
- **Длительность** — применяется к временным уведомлениям; загрузки остаются видимыми до завершения.
- **Заголовок в верхнем регистре** и **жирный заголовок**.
- **Сбросить уведомления** и предпросмотр.

## Вкладка Java

### Среды выполнения Java

Для Java 8, 17, 21 и 25:

- Показывает, установлена ли JRE и какая у неё версия.
- Выбор **поставщика**: «Автоматически», Azul Zulu, Eclipse Temurin, BellSoft Liberica или GraalVM.
- **Установка** или **удаление** управляемой JRE.
- **Обнаружение путей** для поиска внешних установок Java.
- Ручной ввод путей для каждой версии.

Управляемые JRE хранятся в общей папке (`shared/runtimes/jre<version>`).

### Дополнительно

- **Аргументы JVM** — применяются глобально при запуске Minecraft.
- **Переменные среды** — добавляются в процесс Java. Используйте их только если этого требует руководство или мод.

Аргументы и переменные инстанса добавляются после глобальных. Примеры параметров см. в разделе [Что такое Java](/docs/ru-RU/Usage/java).
