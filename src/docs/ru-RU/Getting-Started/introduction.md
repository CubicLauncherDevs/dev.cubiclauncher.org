# Знакомство

CubicLauncher — это лаунчер с открытым исходным кодом для Minecraft: Java Edition. Он позволяет создавать изолированные инстансы и управлять ими, устанавливать версии и загрузчики, управлять аккаунтами, загружать контент из Modrinth и CurseForge, а также настраивать внешний вид с помощью тем.

## Ключевые возможности

- Независимые инстансы с собственной конфигурацией, модами, наборами ресурсов, шейдерами, скриншотами, мирами и серверами.
- Поддержка Vanilla, Fabric, Forge, Quilt и NeoForge.
- Аккаунты Microsoft, Ely.by, CubicAuth, собственные серверы Yggdrasil/Authlib и офлайн-режим.
- Контент из Modrinth и CurseForge: моды, наборы ресурсов, шейдеры и модпаки.
- Управление мирами и серверами для каждого инстанса, с пингом и Quick Play.
- Скины и плащи, хранилище скинов и автоматическое определение классической или стройной модели.
- Java под управлением лаунчера или внешняя, с провайдерами Azul Zulu, Eclipse Temurin, BellSoft Liberica и GraalVM.
- Встроенная консоль с историей, очисткой конфиденциальных данных и загрузкой на mclo.gs.
- Темы (JSON v1 и CBTH v2), фоны, значки и пользовательские шрифты.
- Интерфейс доступен на испанском, английском, французском, немецком, украинском, японском и русском языках.

## Где хранятся мои данные

По умолчанию данные хранятся в папке пользователя, в каталоге `.cubic`:

```
~/.cubic/
├── instances/   # Instances and their content
├── shared/      # Shared versions, libraries, assets and Java runtimes
├── settings/    # Launcher configuration (settings.cub)
├── themes/      # Installed themes
└── skins/       # Skin closet
```

Папки `instances` и `shared` можно перенести на другой диск из раздела **Настройки → Хранилище**. Лаунчер перемещает инстансы с помощью жёстких ссылок, когда это возможно, и позволяет очищать общие файлы для освобождения места; версии и библиотеки будут загружены заново при необходимости.

## Быстрый старт

1. Установите лаунчер, следуя руководству по [установке](/docs/ru-RU/Getting-Started/install).
2. Откройте CubicLauncher и загрузите нужную версию игры.
3. Создайте инстанс с этой версией и, при желании, выберите загрузчик.
4. Войдите через Microsoft, Ely.by/CubicAuth, собственный сервер Yggdrasil или используйте офлайн-режим.
5. Откройте Маркет, чтобы установить моды, наборы ресурсов или шейдеры, либо импортируйте модпак.
6. Настройте ОЗУ, Java, интерфейс и уведомления в разделе **Настройки**.
