# Что такое Java

Java — это язык программирования, который работает на **JVM** (Java Virtual Machine). Minecraft: Java Edition написан на Java, поэтому для запуска ему нужна JVM.

## JRE и JVM

JVM входит в состав **JRE** (Java Runtime Environment), которая включает виртуальную машину, библиотеки Java и всё необходимое для запуска игры.

CubicLauncher может использовать два вида Java:

- **Управляемая**: лаунчер сам скачивает и управляет JRE.
- **Внешняя**: вы используете Java, уже установленную в системе.

:::info Java не устанавливается автоматически
CubicLauncher не скачивает управляемую JRE, пока вы его об этом не попросите. Если Java не установлена, откройте **Настройки → Java** и скачайте нужную версию.
:::

## Версии Java

CubicLauncher умеет устанавливать и находить Java 8, 17, 21 и 25.

Общие рекомендации:

- Java 8 — для старых версий Minecraft.
- Java 17 — для современных версий, которые её требуют.
- Java 21 — для самых последних версий.
- Java 25 — доступна для версий или загрузчиков, которые её запрашивают.

Выбор зависит от того, что указывают версия игры, загрузчик и переопределения инстанса. Лаунчер проверяет манифест и, если версия не указана явно, выводит её из версии Minecraft. Для старого Forge/NeoForge он может сохранить Java 8; для новых версий он автоматически повышает её до Java 17 или 21, когда этого требует загрузчик.

## Провайдеры Java

В **Настройках → Java** можно выбрать провайдера для каждой версии:

- **Azul Zulu** — вариант по умолчанию, сбалансированный и доступный для Java 8, 17, 21 и 25.
- **Eclipse Temurin** — дистрибутив Eclipse и эталонная реализация OpenJDK.
- **BellSoft Liberica** — сборки с долгосрочной поддержкой.
- **GraalVM** — часто быстрее с модами; доступна для Java 17 и выше.

Параметр **Автоматически** использует Azul Zulu и Eclipse Temurin в зависимости от доступности. Если вы меняете провайдера уже установленной JRE, лаунчер может попросить удалить и переустановить её.

## Где хранятся управляемые JRE

Управляемые JRE хранятся в общей папке, в `runtimes/jre<version>`. По умолчанию это `~/.cubic/shared/runtimes/`, но если вы измените расположение общих файлов в **Настройках → Хранилище**, путь к средам выполнения тоже изменится.

## Поиск внешней Java

В **Настройках → Java** можно воспользоваться кнопкой **Найти пути**. Лаунчер ищет исполняемые файлы в `JAVA_HOME` и стандартных системных расположениях и показывает найденные пути для Java 8, 17, 21 и 25. Вы также можете указать путь вручную.

## Java для отдельного инстанса

Каждый инстанс может использовать другую версию Java в своём редакторе:

- Если у инстанса нет переопределений, используется глобальная конфигурация.
- Если вы включите пользовательскую конфигурацию, то сможете выбрать версию Java и собственные аргументы JVM.
- Аргументы инстанса добавляются после глобальных.

## Параметры JVM

Параметры JVM — это опции, передаваемые Java при запуске Minecraft. Они позволяют настроить память, сборщик мусора или системные свойства.

### Где их настраивать

1. Откройте **Настройки** CubicLauncher.
2. Перейдите в **Java**.
3. Найдите **Аргументы JVM** и введите аргументы через пробелы или переносы строк.

Если Minecraft уже открыт, закройте и снова откройте его, чтобы изменения применились. Аргументы JVM для отдельного инстанса также можно задать в редакторе инстанса.

### Распространённые параметры

Эти примеры работают с дистрибутивами HotSpot для Java 8, 17, 21 и 25, например с Eclipse Temurin:

| Параметр | Для чего нужен |
| --- | --- |
| `-Xms1G` | Задаёт начальный размер кучи Java в 1 ГиБ, где хранятся игровые объекты. |
| `-Xmx4G` | Ограничивает кучу до 4 ГиБ. Minecraft может потреблять дополнительную память сверх этого лимита. |
| `-XX:+UseG1GC` | Выбирает G1 в качестве сборщика мусора, который освобождает неиспользуемую память. Он уже является вариантом по умолчанию во многих современных установках Java. |
| `-XX:+ParallelRefProcEnabled` | Включает параллельную обработку ссылок во время сборки мусора; это может сократить время, затрачиваемое на эту задачу. |

Например, чтобы использовать начальную кучу в 1 ГиБ, максимум в 4 ГиБ и сборщик G1:

```text
-Xms1G -Xmx4G -XX:+UseG1GC -XX:+ParallelRefProcEnabled
```

Если вы уже настроили ОЗУ в лаунчере, не указывайте `-Xms` и `-Xmx` в поле параметров, чтобы не дублировать эти настройки:

```text
-XX:+UseG1GC -XX:+ParallelRefProcEnabled
```

Вы можете изменить `4G` на другой лимит в соответствии с доступной памятью и требованиями вашего модпака, оставив память для системы и других программ. Значение `-Xms` должно быть меньше или равно `-Xmx`. Эти настройки не гарантируют больше FPS: результат зависит от вашего оборудования, версии Java и модов.

## Переменные окружения Java

В **Настройках → Java → Переменные окружения** можно задать переменные, которые будут применяться при запуске Minecraft. Используйте их только если этого требует мод, загрузчик или конкретное руководство.

## Рекомендуемая память

В **Настройках → Minecraft** можно увидеть рекомендуемый диапазон исходя из общего объёма ОЗУ. Общие рекомендации:

- 4 ГБ или меньше: 2 ГБ для Minecraft.
- 8 ГБ: от 3 до 4 ГБ.
- 16 ГБ или больше: от 4 до 8 ГБ, в зависимости от модов и шейдеров.

Помните, что система и другие приложения тоже нуждаются в памяти. Глобальная память настраивается в **Настройках → Minecraft → Производительность (ОЗУ)** и может быть переопределена для каждого инстанса.
