# Аккаунты пользователей

CubicLauncher позволяет сохранять несколько аккаунтов и переключаться между ними, не закрывая лаунчер. Каждый инстанс использует активный аккаунт при запуске Minecraft.

## Добавление аккаунта

1. Откройте раздел пользователя на боковой панели.
2. Выберите **Добавить** или **Добавить аккаунт**.
3. Выберите тип аккаунта.

### Microsoft

Есть два способа войти:

- **Из лаунчера** — открывает окно Microsoft для завершения входа.
- **С помощью кода авторизации** — показывает ссылку и код, которые нужно ввести вручную в браузере.

Если у вас уже есть сохранённый аккаунт Microsoft, вы можете выбрать его вместо повторного входа. Сессия автоматически продлевается, когда это возможно.

### Ely.by

Использует предустановленный сервер `https://account.ely.by/api/authlib-injector`. После подключения аккаунта вы можете управлять его скином на странице профиля Ely.by и обновлять предпросмотр в лаунчере.

### CubicAuth

Подключает аккаунт к `https://auth.cubiclauncher.org`. Если у вас ещё нет аккаунта, вы можете зарегистрироваться по ссылке, которую показывает лаунчер.

### Собственный сервер Yggdrasil / Authlib

Позволяет ввести URL любого сервера, совместимого с Yggdrasil/Authlib-injector. Лаунчер сохраняет сервер вместе с аккаунтом.

### Офлайн

Введите имя длиной от 3 до 16 символов. Допускаются только буквы, цифры и знаки подчёркивания (`_`). Этот режим не выполняет аутентификацию через Microsoft или внешний сервер.

## Управление аккаунтами

Из профиля пользователя вы можете:

- **Активировать** аккаунт для будущих запусков.
- **Выйти** из активного аккаунта.
- **Удалить** сохранённый аккаунт.
- Проверить тип аккаунта и связанный с ним сервер.

Токены хранятся в защищённом хранилище системы, когда оно доступно. CubicLauncher никогда не получает ваш пароль Microsoft.

## Просроченные сессии

Если токен аккаунта больше не может быть обновлён, лаунчер показывает уведомление и просит войти снова. В сообщении указывается имя аккаунта и предлагается снова выбрать способ аутентификации. Другие аккаунты и инстансы не изменяются.

## Скины и плащи

Аккаунты, которые это поддерживают, могут управлять своим скином и плащами из профиля.

### Загрузка скина

- Принимаемый формат: `.png`.
- Вы можете перетащить изображение в область загрузки или нажать, чтобы выбрать его.
- Перед сохранением показывается предпросмотр.
- Изменения подтверждаются кнопкой **Сохранить изменения** и могут быть отменены.

### Классическая или стройная модель

CubicLauncher определяет модель по пикселям скина:

- Стройный (Alex) скин выбирает модель **Slim**.
- Классический (Steve) скин выбирает модель **Classic**.
- Стройный скин **нельзя сохранить как классический**, так как на руках появятся чёрные полосы.
- Если определения недостаточно для выбора, вы можете указать модель вручную.
- Переключение с классической на стройную модель разрешено.

### Плащи

- В списке отображаются плащи, доступные для аккаунта.
- Вы можете надеть, снять или сменить активный плащ.
- Изменения скина и плаща сохраняются вместе.
- Если вы сделаете слишком много изменений подряд, лаунчер покажет уведомление об ограничении частоты, и вы сможете повторить попытку через несколько секунд.

### Хранилище скинов

Хранилище позволяет сохранять скины для дальнейшего использования:

- Сохранить текущий скин с именем.
- Переименовать или удалить записи.
- Надеть сохранённый скин на аккаунт.

Хранилище размещается в папке `.cubic/skins/` и не является общим для разных аккаунтов.

### Скины Ely.by

Для аккаунтов Ely.by лаунчер открывает страницу скинов сервиса, где вы можете выбрать или загрузить скин. Когда вы вернётесь, вы сможете обновить предпросмотр и голову из профиля.

## Частые проблемы

- **Кнопка загрузки скина не отображается**: аккаунт или сервер не разрешает менять скин из лаунчера.
- **На руках скина видны чёрные полосы**: стройный скин был сохранён как классический. Загрузите его снова и используйте модель Slim.
- **Сессия Microsoft истекает**: войдите снова из уведомления о просроченной сессии.
- **Не удаётся войти на собственный сервер**: проверьте URL сервера и его совместимость с Yggdrasil/Authlib-injector.
