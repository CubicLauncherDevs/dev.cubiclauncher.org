# Поддержка

Нужна помощь с CubicLauncher? У нас есть несколько официальных каналов, где вы можете получить помощь, сообщить о проблемах и получить поддержку как от сообщества, так и от команды разработчиков.

## Перед обращением за поддержкой

Прежде чем открыть запрос на поддержку, обязательно:

- Проверьте официальную документацию.
- Убедитесь, что используете последнюю версию CubicLauncher.
- Поищите, не сообщалось ли уже о вашей проблеме.
- Соберите соответствующие логи, скриншоты или сообщения об ошибках.

:::tip Совет
Чем больше информации вы предоставите, тем проще будет определить и решить проблему.
:::

## GitHub Issues

При пустых окнах, мерцании или сбоях в Linux сначала ознакомьтесь с [руководством по NVIDIA и Wayland](/docs/ru-RU/guides/nvidia-wayland). При обращении за помощью укажите ваш драйвер, композитор, тип сеанса и результаты тестов. Если лаунчер не открывается, вместо игрового лога можно приложить вывод терминала.

Наш основной способ сообщать об ошибках, запрашивать новые функции или получать техническую поддержку — **Issues** в официальном репозитории.

### Когда использовать GitHub Issues?

Используйте GitHub Issues для:

- Сообщения об ошибках.
- Запроса новых функций.
- Сообщения о проблемах совместимости.
- Сообщения о неожиданном поведении.
- Отслеживания известных проблем.

### Официальный репозиторий

**Репозиторий:** https://github.com/CubicLauncherDevs/CubicLauncher

При создании issue постарайтесь указать:

- Версию CubicLauncher.
- Используемую операционную систему.
- Подробное описание проблемы.
- Шаги для воспроизведения ошибки.
- Соответствующие скриншоты или логи.

:::danger Важно
Прежде чем создавать новую issue, проверьте, не существует ли уже issue, связанной с вашей проблемой.
:::

## Поддержка в Discord

Мы также оказываем поддержку через наш официальный сервер Discord.

**Сервер Discord:** https://discord.com/invite/7VaqSrPukm

### Публичный канал поддержки

Для общих вопросов и типичных проблем вы можете использовать публичный канал поддержки.

Этот канал идеально подходит для:

- Помощи с установкой.
- Проблем с конфигурацией.
- Общих вопросов.
- Быстрого решения вопросов.

Вам могут помочь как участники сообщества, так и члены команды.

### Система тикетов

Если ваша проблема требует персонального внимания или связана с конфиденциальной информацией, вы можете открыть тикет в поддержку.

Мы рекомендуем использовать тикеты для:

- Сложных проблем.
- Индивидуального сопровождения.
- Случаев, требующих предоставления конфиденциальной информации.
- Расширенной поддержки.

После создания тикета член команды рассмотрит ваш случай и ответит как можно скорее.

## Всё ещё нужна помощь?

Если вы не можете найти решение в документации, вы можете связаться с нами через GitHub Issues, публичный канал поддержки в Discord или тикет в поддержку.
