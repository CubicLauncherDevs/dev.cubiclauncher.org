# Установка Dawn Client

[Dawn](https://dawn.gg/) — бесплатный клиент Minecraft Java, который также предлагает **автономный мод Fabric**. Это руководство объясняет, как установить его в CubicLauncher.

:::info Требования
Minecraft 1.17 или выше, загрузчик Fabric. Рекомендуемая версия: 1.20.1.
:::

## 1. Скачайте автономную версию

Перейдите на [dawn.gg](https://dawn.gg/) и скачайте вариант **Download Standalone (Fabric Mod Jar)**.

<div class="docs-img-wrap">
  <img src="https://i.imgur.com/x1yRbHy.png" alt="Кнопка Download Standalone на dawn.gg" />
</div>

## 2. Создайте инстанс

1. Нажмите **Создать инстанс**.
2. В окне создания выберите вкладку **Fabric** и укажите версию **1.20.1**.
3. Введите название инстанса и нажмите **Создать**.

## 3. Добавьте мод

1. Откройте папку инстанса в `.cubic/instances/<name>/`.
2. Скопируйте файл `.jar` **Dawn standalone** в папку `mods/`.
3. На вкладке **Детали** инстанса откройте **Маркет** и скачайте **Fabric API** для версии 1.20.1.

## 4. Запуск

Нажмите **Играть**. Dawn загрузится как мод вместе с Fabric.
