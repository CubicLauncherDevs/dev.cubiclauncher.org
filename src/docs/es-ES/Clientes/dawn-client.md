# Instalar Dawn Client

[Dawn](https://dawn.gg/) es un cliente gratuito para Minecraft Java que también ofrece un **mod standalone** para Fabric. Esta guía explica cómo instalarlo dentro de CubicLauncher.

:::info Requisitos
Minecraft 1.17 o superior, loader Fabric. Versión recomendada: 1.20.1.
:::

## 1. Descargar el standalone

Entrá a [dawn.gg](https://dawn.gg/) y descargá la opción **Download Standalone (Fabric Mod Jar)**.

<div class="docs-img-wrap">
  <img src="https://i.imgur.com/x1yRbHy.png" alt="Botón Download Standalone en dawn.gg" />
</div>

## 2. Crear la instancia

1. Hacé clic en **Crear Instancia**.
2. En la ventana de creación, seleccioná la pestaña **Fabric** y elegí la versión **1.20.1**.
3. Completá el nombre de la instancia y presioná **Crear**.

## 3. Colocar el mod

1. Abrí la carpeta de la instancia dentro de `.cubic/instances/<nombre>/`.
2. Copiá el archivo `.jar` del **Dawn standalone** dentro de la carpeta `mods/`.
3. En la pestaña **Detalles** de la instancia, abrí el **Market** y descargá **Fabric API** para la versión 1.20.1.

## 4. Iniciar

Hacé clic en **Jugar**. Dawn se cargará como mod junto con Fabric.
