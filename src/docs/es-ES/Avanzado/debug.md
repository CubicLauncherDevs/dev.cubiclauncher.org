# Diagnóstico del launcher

## Problemas gráficos en Linux

Para ventanas vacías, parpadeos o cierres al redimensionar, consultá [Problemas gráficos en Linux: NVIDIA y Wayland](/docs/es-ES/guias/nvidia-wayland). Incluye las variables de WebKitGTK, cómo comparar resultados y qué datos recopilar si el launcher no abre.

## Logs y soporte

Consultá [Diagnóstico y logs](/docs/es-ES/Uso/diagnostico) para problemas de las instancias y [Soporte](/docs/es-ES/guias/soporte) para reportar un fallo con los pasos para reproducirlo.
