# Contribuir

Se aceptan contribuciones de código, documentación, traducciones y reportes de bugs.

## Reportar un problema

Abrí un issue con:

- Descripción clara del problema
- Pasos para reproducir
- Versión de CubicLauncher y sistema operativo
- Enlace al log (mclo.gs) si aplica

## Cambios de código

- Antes de abrir el PR, asegurate de que las comprobaciones pasan (`lint`, `check`, tests y lints de Rust).
- Seguí las convenciones del proyecto y el estilo de código.

## Traducciones

Las instrucciones de i18n y el repositorio de traducciones están enlazados desde la guía de contribución del proyecto.
