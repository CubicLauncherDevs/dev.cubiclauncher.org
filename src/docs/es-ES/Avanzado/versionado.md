# Versionado y lanzamientos

El proyecto sigue un esquema de versionado documentado en su guía de versiones. Las publicaciones estables aparecen en GitHub Releases y pueden incluir instaladores por plataforma.

## Canales de actualización

- Estable: recomendado para la mayoría de usuarios.
- Prerelease: acceso anticipado a nuevas funciones; puede tener cambios inestables.

Podés cambiar el canal desde la configuración del launcher.
