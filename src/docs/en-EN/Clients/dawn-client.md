# Install Dawn Client

[Dawn](https://dawn.gg/) is a free Minecraft Java client that also offers a **Fabric standalone mod**. This guide explains how to install it inside CubicLauncher.

:::info Requirements
Minecraft 1.17 or higher, Fabric loader. Recommended version: 1.20.1.
:::

## 1. Download the standalone

Go to [dawn.gg](https://dawn.gg/) and download the **Download Standalone (Fabric Mod Jar)** option.

<div class="docs-img-wrap">
  <img src="https://i.imgur.com/x1yRbHy.png" alt="Download Standalone button on dawn.gg" />
</div>

## 2. Create the instance

1. Click **Create Instance**.
2. In the creation window, select the **Fabric** tab and choose version **1.20.1**.
3. Fill in the instance name and click **Create**.

## 3. Add the mod

1. Open the instance folder inside `.cubic/instances/<name>/`.
2. Copy the **Dawn standalone** `.jar` file into the `mods/` folder.
3. In the instance **Details** tab, open the **Market** and download **Fabric API** for version 1.20.1.

## 4. Launch

Click **Play**. Dawn will load as a mod along with Fabric.
