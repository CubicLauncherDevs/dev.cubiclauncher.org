# Servers and worlds

Each instance has its own world and server list, so you don't mix things between Vanilla and your modpacks.

## Worlds

- List of local worlds with name, folder and Minecraft version.
- Search and sort to find worlds quickly.
- Open the `saves/` folder to make backups or import a world.
- Import a world from a ZIP or from a folder.
- Delete worlds you no longer use from the same view.

Worlds are stored inside `saves/` in the instance folder.

## Servers

- Add servers with name, host and port.
- Edit or delete servers from the list.
- The launcher checks the status (ping) and shows the MOTD, version and connected players.
- Servers are stored in the instance's list (`servers.dat`).

## Quick connect

- From the server view you can start Minecraft and join automatically.
- For compatible servers, host/port is passed using Quick Play.
- If the server does not respond, check the host, the port and your connection; the ping can fail even if the server is available.

## Import and migrate

When importing or migrating an instance from another launcher, CubicLauncher copies the worlds (`saves`) and the server list (`servers.dat`) along with the rest of the content. See [Migration from other launchers](/docs/en-EN/Usage/migration).
