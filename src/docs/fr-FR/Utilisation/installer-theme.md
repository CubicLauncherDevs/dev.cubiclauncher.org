# Comment installer un thème

Installer un thème dans CubicLauncher est très simple. Suivez ces 3 étapes.

## Étape 1 : Télécharger le thème

Cherchez un thème dans la section https://www.cubiclauncher.org/themes de la page ou dans le dépôt officiel https://github.com/CubicLauncherDevs/Themes. Téléchargez-le en fichier ZIP ou CBTH.

<div class="docs-img-wrap">
  <img src="https://i.imgur.com/YJ9ujlR.png" alt="Bouton de téléchargement" />
</div>

## Étape 2 : Glisser le thème dans le launcher

Glissez-déposez le fichier ZIP ou CBTH téléchargé directement sur la fenêtre de CubicLauncher. Le launcher l'installera automatiquement.

<div class="docs-img-wrap">
  <img src="https://i.imgur.com/YJ9ujlR.png" alt="Step2" />
</div>

## Étape 3 : Sélectionner le thème

Ouvrez CubicLauncher, allez dans le sélecteur de thèmes et choisissez celui que vous venez d'installer.

<div class="docs-img-wrap">
  <img src="https://i.imgur.com/NoBw8vS.png" alt="Configurer le thème dans le launcher" />
</div>

Et voilà ! Votre thème est installé.

## Thèmes intégrés

CubicLauncher inclut les thèmes **Sombre**, **Lime**, **Clair** et **Halloween 2026**. Le thème Halloween a été renouvelé pour 2026 avec une nouvelle image d'arrière-plan et une palette indigo nocturne. Les anciens thèmes Rosé Pine ne font plus partie du launcher, mais vous pouvez toujours utiliser un thème installé manuellement s'il est compatible.

Vous pouvez revenir à un thème intégré depuis le sélecteur de thèmes à tout moment.
