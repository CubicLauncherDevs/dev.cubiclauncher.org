# Installer Dawn Client

[Dawn](https://dawn.gg/) est un client Minecraft Java gratuit qui propose également un **mod autonome Fabric**. Ce guide explique comment l'installer dans CubicLauncher.

:::info Prérequis
Minecraft 1.17 ou supérieur, loader Fabric. Version recommandée : 1.20.1.
:::

## 1. Télécharger le mod autonome

Allez sur [dawn.gg](https://dawn.gg/) et téléchargez l'option **Download Standalone (Fabric Mod Jar)**.

<div class="docs-img-wrap">
  <img src="https://i.imgur.com/x1yRbHy.png" alt="Bouton Download Standalone sur dawn.gg" />
</div>

## 2. Créer l'instance

1. Cliquez sur **Créer une instance**.
2. Dans la fenêtre de création, sélectionnez l'onglet **Fabric** et choisissez la version **1.20.1**.
3. Remplissez le nom de l'instance et cliquez sur **Créer**.

## 3. Placer le mod

1. Ouvrez le dossier de l'instance dans `.cubic/instances/<nom>/`.
2. Copiez le fichier `.jar` du **Dawn standalone** dans le dossier `mods/`.
3. Dans l'onglet **Détails** de l'instance, ouvrez le **Market** et téléchargez **Fabric API** pour la version 1.20.1.

## 4. Démarrer

Cliquez sur **Jouer**. Dawn se chargera comme un mod avec Fabric.
