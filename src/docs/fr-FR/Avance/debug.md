# Diagnostic du launcher

## Problèmes graphiques sous Linux

Pour les fenêtres vides, les scintillements ou les plantages au redimensionnement, consultez [Problèmes graphiques sous Linux : NVIDIA et Wayland](/docs/fr-FR/guides/nvidia-wayland). Ce guide présente les variables WebKitGTK, la comparaison des résultats et les informations à recueillir si le launcher ne s'ouvre pas.

## Signaler un problème

Consultez le [Support](/docs/fr-FR/guides/support) pour signaler un bug avec les logs et les étapes permettant de le reproduire.
